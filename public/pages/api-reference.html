🗄️ 开通与修改专属网页API详细文档

这份文档面向**主站后端开发人员 / 系统架构师**。此文档定义了主站与边缘节点进行交互的核心API。

由于优化了底层架构，现在无论是**启用域名**、**首次使用模板**，还是**后续修改域名的模板**，**均统一调用同一个接口** (`POST /admin/render-page`)。边缘节点会自动处理覆盖和缓存刷新逻辑。

核心接口详情 ⚙️

POST https://romancespace.885201314.xyz/admin/render-page

Headers (必填)

  • X-Admin-Key: 你的平台通讯安全密钥
  • Content-Type: application/json

公共参数说明

参数名 类型 必填？ 说明
subdomain String 必须 分配给该用户的专属三级域名前缀。例：传 xiaoming = xiaoming.885201314.xyz
type String 必须 使用的模板代号（如 love_letter）。必须是已被上传到系统的模板名。
data Object 可选 注入模板的具体数据（不同场景传入不同的数据内容）。

场景一：启用域名 (仅绑定，不传入具体数据)

用户首次开通，此时还未填写任何表白/纪念内容的场景。我们希望生成一个带有“默认占位文字”的网页。

传参方式：data 参数传 {} 即可，系统会自动使用模板 schema.json 中预设的 default 默认值进行渲染。

cURL
Fetch
curl -X POST https://romancespace.885201314.xyz/admin/render-page \
  -H "X-Admin-Key: 你的超强安全密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "subdomain": "xiaoming",
    "type": "anniversary",
    "data": {}
  }'
const response = await fetch("https://romancespace.885201314.xyz/admin/render-page", {
  method: "POST",
  headers: { "X-Admin-Key": "你的超强安全密钥", "Content-Type": "application/json" },
  body: JSON.stringify({
    subdomain: "xiaoming",
    type: "anniversary",
    data: {} 
  })
});

场景二：首次使用模板 (开通并立刻附带资料)

用户在一个表单中同时完成了选模板 + 填写自定义资料流，主站将收集到的数据一次性提交开通。

传参方式：将用户填写的数据填入 data 对象内。这会完全替换掉模板内设的默认值。

cURL
Fetch
curl -X POST https://romancespace.885201314.xyz/admin/render-page \
  -H "X-Admin-Key: 你的超强安全密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "subdomain": "xiaoming",
    "type": "anniversary",
    "data": { 
      "names": ["小明", "红红"], 
      "startDate": "2023-01-01" 
    }
  }'
const response = await fetch("https://romancespace.885201314.xyz/admin/render-page", {
  method: "POST",
  headers: { "X-Admin-Key": "你的超强安全密钥", "Content-Type": "application/json" },
  body: JSON.stringify({
    subdomain: "xiaoming",
    type: "anniversary",
    data: { names: ["小明", "红红"], startDate: "2023-01-01" }
  })
});

场景三：后续修改域名下的模板资料

小明在使用 anniversary 模板期间，希望把 startDate 可以修改成 2024-02-14，或者更换另一个全新的模板。

传参方式：依然是调用本接口，无论是更换 type 还是单纯更换 data，系统都会在后台自动冲刷掉旧页面，重新生成静态网页，并秒速清理全球缓存。
