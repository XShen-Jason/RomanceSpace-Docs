🖥️ 平台前台 (SPA/Vite) 本地开发与部署指南

架构定位： 前端（RomanceSpace-Frontend）是一个纯粹的单页应用 (SPA)。它不包含任何数据库密码，也跨出了高危区。它的一切流转都是通过调用由 VPS 提供的 API 实现的。

一、 本地开发环境配置

1. 获取源码并安装

git clone https://github.com/XShen-Jason/RomanceSpace-Frontend.git
cd RomanceSpace-Frontend
npm install

2. 配置环境变量

前端对环境的诉求极少。请在根目录根据 .env.example 创建一份 .env 文件：

# Vite 暴露的公共变量需以 VITE_ 前缀开头
# 指向你的 VPS 后端 API 地址
VITE_API_URL=http://localhost:3000

# （可选）安全请求密钥（如果想做简单的内部防刷验证）
VITE_ADMIN_KEY=your_super_secret_key

3. 启动开发服务器

npm run dev

如果你在本地开发，确保此时位于本地 `localhost:3000` 的后端程序（或远程的 API VPS）正在运行，否则跨域拉不出数据。

二、 部署至 Cloudflare Pages (极简自动化)

因为纯静态的属性，推荐直接使用零成本的 Cloudflare Pages (不是 Worker!) 进行托管。

步骤流程：

  1. 登录 Cloudflare -> 点击左侧的 Workers & Pages -> Pages -> 连接到 Git。
  2. 选择你的 RomanceSpace-Frontend GitHub 仓库。
  3. 构建设置项：
    • 框架预设 (Framework preset)：Vite (或 None/Vue/React 视脚手架而定)
    • 构建命令 (Build command)：npm run build
    • 构建输出目录 (Build output directory)：dist
  4. 环境变量 (非常重要)：展开环境变量设置，填入：
    • 键名: VITE_API_URL -> 值: https://api.885201314.xyz （填你真实的后端 VPS 域名）
  5. 点击保存并部署。稍等 1 分钟即可全球秒开。

三、 C端用户自定义域名绑定 (进阶)

系统默认生成的分享链接如 xiaoming.885201314.xyz 是由泛解析 Worker 完成映射拦截的，这部分和前台大厅 (Frontend) 项目在物理上其实是解藕的。主页的 DNS (如 www.885201314.xyz) 会通过 CNAME 静态解析到刚刚建好的 Pages 项目名即可。
