🧑‍💻 新模板开发与自动化部署指南 (笔记)

本指南面向想要为系统贡献新网页样式的切图仔。系统第五大独立仓库 RomanceSpace-Templates 没有任何复杂的构建工具，纯手工打造。它的灵魂在于一份名为 config.json 的“使用说明书”。

💡 为什么强调脱离构建工具？ (分析)
这些模板是要被人随时替换字符并且原封不动塞进 Cloudflare 边缘缓存的。如果是经过了高度打包的 React 或 Vue 产物，后端 VPS 甚至没法用正则找准 `{{name}}` 在哪个位置。越原始的 HTML/CSS/JS，对于这套系统来说越珍贵。
🤖 AI 辅助开发？ 我们专门准备了 《AI 专用模板开发规范》，包含一键复制的 Prompts！

一、 标准化的结构拆解 (动手干)

1
搭设你的小作坊
在仓库的根目录建一个新文件夹（比如 my_card），保证它的结构非常简单：
templates/my_card/
├── index.html —— (必填) 你写的静态网页本体
├── config.json —— (必填) 极其重要的替换词典
├── style.css —— (可选) 让网民惊叫的 CSS 极品特效
└── img/bg.jpg —— (可选) 你引用的各种小素材
2
打上灵魂替换签
在你写好的 index.html 里，不要把字写死。把你想让用户自己填的地方，用极其明显的双大括号 {{}} 圈起来： 
<h1>{{title}}</h1>
<p>这封信是 {{author}} 写给你的。</p>
3
撰写 Config.json 说明书
新建 config.json，这个文件是给咱们的前端 React 和后端 VPS 读的。告诉它们这个模板需要收集什么词： 
{
  "name": "my_card",
  "static": false,
  "fields": [
    { "id": "title", "label": "标题", "type": "text", "default": "我的标题" },
    { "id": "author", "label": "署名", "type": "text", "default": "神秘人" }
  ]
}

二、 推向线上 (两套部署方案)

方案 A：可视化后台一键上传（推荐运营人员首选）

系统在前端主站为您提供了一个极简的隐藏管理后台，完全脱离枯燥的命令行代码。

1
登录后台：
浏览器访问 https://www.885201314.xyz/admin/upload，输入管理员密码。
2
拖拽上传：
将你写好的 index.html 和 config.json （以及配套图片）全部选中，拖进网页的上传框内。
3
秒级生发：
填写好你的模板英文文件夹名，点击“一键发布”。所有文件会瞬间直达云端 R2 存储桶，并在前台立刻生效。

方案 B：GitOps 自动化流水线（推荐资深极客）

如果你将模板文件夹 git commit 提交到 Github 的 RomanceSpace-Templates 仓库主分支。仓库里的 Github Actions 就会自动启动：为你自动打包文件夹 -> 跨海调用 VPS 的 /api/template/upload 接口 -> 自动推入 R2。

# 极客的日常只要敲三行代码：
git add .
git commit -m "feat: 新增了一个表白特效网页"
git push

就是这么丝滑！根据您的团队人员构成，随意选择最合适的一套方案即可。
