🗄️ 开通与修改专属网页 API 详细文档

由于优化了底层架构，现在无论是启用域名、首次使用模板，还是修改资料，均统一调用同一个后端的写入接口。只要用户点击生成，系统便会在后台重新向 R2 仓库覆盖新的专属 HTML。

💡 核心配置提醒： 在 RomanceSpace-Frontend 中，你需要将 VITE_API_BASE_URL 设定为你的 VPS 后端地址。而此处的 POST 交互正是一切的开始。打开生成的网页链接相当于直接访问网关 Worker。

核心接口详情 ⚙️

POST https://api.885201314.xyz/api/project/render

公共参数说明

参数名 类型 必填？ 说明
subdomain String 必须 分配给该用户的专属三级域名前缀。例：传 xiaoming = xiaoming.885201314.xyz
type String 必须 使用的模板代号（如 love_letter）。必须是已被上传到系统的模板名。
data Object 可选 注入模板的具体数据（不同场景传入不同的数据内容）。

操作流程举例

1
步骤 1：仅启用域名 (不传数据)
举例：小明刚注册但没填内容，发起一个空数据请求以呈现空网页：
cURL 示例
Fetch 示例
curl -X POST https://api.885201314.xyz/api/project/render \
  -H "Content-Type: application/json" \
  -d '{
    "subdomain": "xiaoming",
    "type": "anniversary",
    "data": {}
  }'
const response = await fetch("https://api.885201314.xyz/api/project/render", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    subdomain: "xiaoming",
    type: "anniversary",
    data: {} 
  })
});
2
步骤 2：填充与覆盖自定义数据
举例：小红填写了数据提交，后端接收后替换上一步的空内容网页，实现了刷新与覆盖：
cURL 示例
Fetch 示例
curl -X POST https://api.885201314.xyz/api/project/render \
  -H "Content-Type: application/json" \
  -d '{
    "subdomain": "xiaoming",
    "type": "anniversary",
    "data": { 
      "names": ["小明", "红红"], 
      "startDate": "2023-01-01" 
    }
  }'
const response = await fetch("https://api.885201314.xyz/api/project/render", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    subdomain: "xiaoming",
    type: "anniversary",
    data: { names: ["小明", "红红"], startDate: "2023-01-01" }
  })
});
