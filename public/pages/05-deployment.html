Chapter 5

部署圣经：从服务器到边缘

本章记录了如何从零开始部署 RomanceSpace 的全栈环境，涵盖 VPS、Nginx、Cloudflare 等各个关键环节。

1. 中央 API 后端 (VPS 部署)

后端运行在专有的 Linux VPS 上，通过 PM2 进行守护，并由 Nginx 暴露 API 统一出口。

Nginx 关键配置 (动静分离与代理)

server {
    listen 80;
    server_name www.885201314.xyz api.885201314.xyz;

    # 1. 动静分离：前端 React 打包文件
    location / {
        root /var/www/romancespace-frontend/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 2. 修改 API 接口中转
    location /api/ {
        proxy_pass http://localhost:3000/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        # 绝杀跨域：内网中转，外部看起来是同一个域名
    }
}

PM2 进程守卫

# 在服务器项目目录下执行
npm install
pm2 start src/server.js --name "rs-api"
pm2 save
pm2 startup

2. 边缘路由 (Worker) 部署

Worker 部署在 Cloudflare，其核心在于正确绑定环境变量与命名空间。

部署命令

cd RomanceSpace-Worker
npx wrangler deploy

权限绑定清单：

  • KV Namespace: 绑定 ROMANCESPACE_KV，用于存储路由信息。
  • R2 Bucket Binding: 绑定 ROMANCESPACE_R2，用于读取静态 HTML。
  • Custom Domains: 将 *.885201314.xyz 绑定到该 Worker 上。
