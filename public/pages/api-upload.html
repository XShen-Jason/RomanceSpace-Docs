🚀 开发者上传模板接口

如果您希望在自己的主站后台搭建一套 “可视化模板上传面板”，可以通过调用此接口，将包含 HTML/CSS/JS/图片 等模板文件直传至 Cloudflare 边缘节点。

一旦上传成功，新版模板立刻生效，系统还会在后台平滑滚动更新所有使用过此模板的老用户专属网页。

接口详情 ⚙️

POST https://romancespace.885201314.xyz/admin/upload-template

Headers (必填)

  • X-Admin-Key: 安全密钥
  • Content-Type: multipart/form-data

Form-Data 解析规则

在这个上传表单中，你至少要包含：

  • 键名 templateName，值是一个字符串 (如 my_card)。最长 50个字符，只能是英文字母、数字和下划线。
  • 后续其他键名，键名就是文件在云端的相对路径+文件名，而键值就是那个真实的二进制文件 (File)。
    例如：你有一张图片叫 `bg.jpg`，你希望它存到静态目录里的 `img/bg.jpg`，那你在 form-data 里的 key 就写 `img/bg.jpg`。

🚨 强制验证项：一次合法的上传里，必须包含一个名为 index.html 的文件，否则接口将会退回。

代码调用示例

cURL
Node.js (FormData)
# 这个命令展示了如何同时传文本名，加上2个文件
curl -X POST https://romancespace.885201314.xyz/admin/upload-template \
  -H "X-Admin-Key: 你的超强密钥" \
  -F "templateName=love_letter" \
  -F "index.html=@./templates/love_letter/index.html" \
  -F "style.css=@./templates/love_letter/style.css"
// 前端或 NodeJS (需引入 fs) 示例
const formData = new FormData();
formData.append("templateName", "love_letter");

// 将本地文件塞进入，注意左边的第一个参数 (key) 就是你想让它在云端的路径。
formData.append("index.html", fs.createReadStream("./templates/love_letter/index.html"));
formData.append("style.css", fs.createReadStream("./templates/love_letter/style.css"));
formData.append("schema.json", fs.createReadStream("./templates/love_letter/schema.json"));

const response = await fetch("https://romancespace.885201314.xyz/admin/upload-template", {
  method: "POST",
  headers: {
    "X-Admin-Key": "你的超强密钥"
    // 切记：Fetch 碰到 FormData 时会自动加上带有 boundary 的正确 Content-Type，不要手写 Content-Type!!!
  },
  body: formData
});

const result = await response.json();
console.log("上传成功！预览地址：", result.previewUrl);
