Chapter 5

部署圣经：全栈 VPS 部署指南

本指南教你从零开始，在同一台 VPS 上部署和托管 RomanceSpace 的后端（Node.js）和前端（React），并实现最高性能的“Nginx 动静分离”与“相对路径 0 延迟调用”。

1. 阶段一：环境准备

如果你的 VPS 是一台纯净的 Ubuntu 系统，你需要先安装三个核心软件：Node.js, PM2, Nginx。

# 1. 更新系统并安装 Nginx 和 Git
sudo apt update
sudo apt install -y nginx git curl certbot python3-certbot-nginx

# 2. 安装 Node.js (推荐 20.x 长期支持版)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# 3. 安装 PM2 (管理后端进程的神器)
sudo npm install -g pm2

2. 阶段二：部署后端 (Node.js API)

1
克隆代码与安装依赖： 
cd /opt
sudo git clone https://github.com/XShen-Jason/RomanceSpace-Backend.git
cd RomanceSpace-Backend
sudo npm install
2
配置环境变量：编辑 .env 文件。注意：后端必须使用 SUPABASE_SERVICE_ROLE_KEY 以跳过 RLS 检查。 
PORT=3000
SUPABASE_URL=...
SUPABASE_SERVICE_ROLE_KEY=...
CF_ACCOUNT_ID=...
CF_API_TOKEN=...
CF_KV_NAMESPACE_ID=...
CF_R2_BUCKET=...
3
启动并守护进程： 
pm2 start src/app.js --name "romancespace-api"
pm2 save
pm2 startup

3. 阶段三：部署前端 (React)

让前端和后端在同一个 /opt 目录下做邻居，通过 Nginx 实现纯物理局域网转发。

1
从源码构建： 
cd /opt
sudo git clone https://github.com/XShen-Jason/RomanceSpace-Frontend.git
cd RomanceSpace-Frontend
sudo npm install
2
Auth 注入：编辑 .env 填入 VITE_SUPABASE_URL 和 VITE_SUPABASE_ANON_KEY，这是前端登录必备。
3
执行构建：构建成功的资源将生成在 dist/。 
sudo npm run build

4. 阶段四：Nginx 终极网关配置

配置 Nginx 统管大局，做到动静分离、跨域消除、预览直连。

# /etc/nginx/conf.d/romancespace.conf

server {
    listen 80;
    server_name 885201314.xyz www.885201314.xyz;

    # 1. 前端 React 静态资源
    location / {
        root /opt/RomanceSpace-Frontend/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 2. 内网转发后端 API (3000 端口)
    location /api/ {
        proxy_pass         http://127.0.0.1:3000;
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
    }

    # 3. 模板预览直连 (BSR 骨架分发)
    location /preview/ {
        proxy_pass         http://127.0.0.1:3000/api/template/preview/;
        proxy_set_header   Host $host;
    }
    
    # 4. 模板静态资产加速 (^~ 防止正则截获)
    location ^~ /assets/ {
        proxy_pass         http://127.0.0.1:3000;
        proxy_set_header   Host $host;
    }

    # 5. [优化] 模板列表 JSON 静态服务
    location = /templates.json {
        alias /opt/cache/templates.json;
        add_header Content-Type application/json;
        add_header Access-Control-Allow-Origin *;
    }
}

5. 阶段五 & 六：DNS设置、SSL与极速更新

Cloudflare DNS 设置

在 Cloudflare 面板 -> DNS 设置里，将以下记录设为 灰色云朵 (DNS Only)：

  • A www 指向 VPS_IP
  • A @ (root) 指向 VPS_IP
  • A api 指向 VPS_IP

获取 SSL 证书 (小绿锁)

sudo certbot --nginx -d 885201314.xyz -d www.885201314.xyz -d api.885201314.xyz

日后更新指南

代码 Push 后，在 VPS 执行：

  • 后端更新：cd /opt/RomanceSpace-Backend && git pull && pm2 restart romancespace-api
  • 前端更新：cd /opt/RomanceSpace-Frontend && git pull && npm run build (Nginx 自动感知，无需重启)
