Chapter 7

API 字典：核心功能汇总

本章为开发者提供了 RomanceSpace Backend 暴露的所有核心 API 接口说明。

1. 模板管理 (Template APIs)

接口 方法 说明
/api/template/list GET 获取全量可用模板列表。
/api/template/raw/:name GET 获取指定模板的原始 HTML（BSR 使用）。
/api/template/upload POST (Admin) 上传新模板包。

2. 项目渲染与发布 (Project APIs)

接口 方法 说明
/api/project/render POST 接收表单数据，渲染 HTML 并写入 R2/KV。
/api/project/check-subdomain GET 检查子域名是否已被占用。
/api/project/my-listing GET (Auth) 列出当前用户拥有的页面。

3. 系统运维 (System Ops)

接口 方法 说明
/api/project/config/refresh-blocklist POST (Admin) 强制通知 VPS 刷新内存中的域名黑名单。
/api/auth/status GET 校验当前登录状态。
💡 鉴权方式：
除了公开的渲染与查重接口，大部分涉及用户资产的 API 均通过 Supabase Session Token 进行鉴权。
