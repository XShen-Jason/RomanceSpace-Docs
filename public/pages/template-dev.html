🧑‍💻 模板开发与自动化部署指南

本指南面向前端同学。模板作为体系的第五大独立仓库 RomanceSpace-Templates，它的开发极其简单。最核心的配置就是其专有的 schema.json 骨架合约词典。

一、标准化的模板结构拆解步骤

1
步骤 1：构建文件夹
举例：在仓库里建一个 my_card 目录。
templates/my_card/
├── index.html (必填) 网页本体
├── schema.json (必填) 你的替换词典
├── style.css (可选) CSS 样式
└── img/bg.jpg (可选) 图片挂载
2
步骤 2：撰写灵魂替换签
举例：在你写的纯天然 index.html 中，给所有变量绑上双括号 {{}}： 
<h1>{{title}}</h1>
<p>这是由 {{author}} 给你留的一段话。</p>
3
步骤 3：定义 Schema.json
举例：它是给后端认人的关键配置文件，这正是本仓库的核心： 
{
  "static": false,
  "fields": [
    { "key": "title", "type": "string", "default": "默认大标题" },
    { "key": "author", "type": "string", "default": "神秘人" }
  ]
}

二、通过 GitHub Actions 推向线上 (重头戏)

💡 核心配置 RS_ADMIN_KEY：
确保你的 GitHub 仓库内填好了属于部署管理员的 Secret。随后你只需要敲下面两行： 
# 这个推送会直接激发核心流水线帮您打成 ZIP 调用 API 上传至系统仓库。
git add .
git commit -m "feat: my first UI template"
git push

一旦覆盖上传，引擎将在后台无感刷新全球所有这套模板老用户的静态页！
