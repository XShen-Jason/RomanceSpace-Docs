🖥️ 平台后端系统 (VPS) 部署全指南

架构定位： 在这个极致追求并发的 CQRS 架构中，VPS 后端是唯一的“写入中心”和“模板渲染引擎”。它处理复杂的逻辑，生成静态 HTML，并将其一脚踢进 Cloudflare 仓库，以保持边缘节点的绝对轻量。

一、 服务器配置要求

  • 操作系统： Ubuntu 22.04 LTS 或 Debian 11/12 (推荐)
  • 最低配置： 1核 CPU / 1GB 内存 / 10GB 磁盘 (本架构极其轻量，10块钱轻量云即可跑满)
  • 前置环境： Node.js v18+，NPM / Yarn

二、 基础环境安装

1. 安装 Node.js 与 PM2

# 更新包列表
sudo apt update

# 下载并安装 Node.js 20.x 
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# 全局安装 PM2 (进程守护守护程序)
sudo npm install -g pm2

三、 拉取代码与环境配置

1. 下载代码

git clone https://github.com/XShen-Jason/RomanceSpace-Backend.git
cd RomanceSpace-Backend

# 安装本地依赖包
npm install

2. 配置极度关键的 .env 文件

这个文件掌管了从 VPS 通往大洋彼岸 Cloudflare 仓库的各种命脉钥匙。请在根目录新建 .env：

# ==========================================
# 1. 基础服务器设置
# ==========================================
PORT=3000
NODE_ENV=production

# 你自定义的通讯暗号，前端调用此 API 必须带上它，防止被白嫖接口
ADMIN_API_KEY="your_super_secret_key"

# ==========================================
# 2. Cloudflare R2 设置 (用于上传渲染好的 HTML 和模板)
# ==========================================
R2_ENDPOINT="https://xxxxxx.r2.cloudflarestorage.com"
R2_ACCESS_KEY_ID=""
R2_SECRET_ACCESS_KEY=""
R2_BUCKET_NAME=""
# 前台访问的静态子域名（套了CF的公共访问域名）
R2_PUBLIC_URL="https://assets.885201314.xyz"

# ==========================================
# 3. Cloudflare KV 设置 (用于注册路由 host -> html)
# ==========================================
CF_ACCOUNT_ID=""
KV_NAMESPACE_ID=""
CF_API_TOKEN=""

# ==========================================
# 4. Supabase 设置 (新架构核心业务数据库)
# ==========================================
SUPABASE_URL="https://xxxx.supabase.co"
SUPABASE_SERVICE_ROLE_KEY="eyJhbG..."

四、 启动与守护进程

千万不要使用 npm start 在服务器上裸奔，终端一关服务就挂了。请使用 PM2 守护之。

# 通过 PM2 启动项目，并给它起个名字
pm2 start src/app.js --name "romancespace-backend"

# 保存当前运行状态，这样重启服务器后 PM2 会自动拉起它
pm2 save
pm2 startup

如果后续你拉取了更新代码：

git pull
npm install
pm2 restart romancespace-backend

五、 反向代理与 HTTPS (Nginx)

VPS 内部跑在 3000 端口，前端和访问者进不去，你需要 Nginx 把 80/443 端口代理给 3000，并挂载 SSL 证书。

sudo apt install nginx

配置 /etc/nginx/sites-available/romancespace：

server {
    listen 80;
    server_name api.885201314.xyz;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        
        # 允许上传大文件（模板可能附带大体积图片）
        client_max_body_size 50M;
    }
}

如果你将域名托管在 Cloudflare，SSL 推荐开启 Flexible/Full 模式，CF 会自动全域 HTTPS，你 VPS 只要暴露 80 端口给 CF 即可（最省事）。
