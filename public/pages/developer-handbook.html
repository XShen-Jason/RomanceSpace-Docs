📖 RomanceSpace 开发者终极入场券 (架构笔记)

欢迎来到高并发、低成本、高净值的系统架构！不要被它庞大的五大仓库体系吓到。所有的组件只服务于一个核心思想。

💡 读写分离 & 边缘存储 (核心分析)：
传统的单体网站，几万人进去就把数据库挤炸了。而我们做的是降维打击：“让小服务器安安静静排队造死页面（写），让全球最大的 CDN 替我们分发这些页面给粉丝看（读）！”

一、 四大山头的通力合作 (如何做)

1
🎨 模板样板间 (Templates)
装潢队的材料库。由一堆极度古早、纯天然无污染的 HTML/CSS/JS 组成。为了让 VPS 能直接用正则暴击它，我们禁用了任何华丽的 Webpack 打包手段。
2
🖥️ 前端大堂 (Frontend)
用户充值、选购、填表的地方。利用最新的 BSR (浏览器渲染) 技术，在用户修改词句时，无需向服务器发请求，而是把模板骨架拿到本地 Iframe 里一毫秒变幻出预览图。
3
⚙️ 后端加工厂 (Backend)
全村唯一的写权限拥有者。为了极致节省大厂的额度，我们连封存黑名单词汇这种事都不敢天天读库。而是设计了“零配额消耗体系”，将黑名单缓存在 VPS 的 V8 引擎内存里，直到管理员手动下派雷达通知才更新。
4
🛜 边缘网关 (Worker)
最凶狠的保安大队。百万粉丝汹涌而来，只在第一个人访问时去 R2 仓库拿了次原件。保安们给文件盖上一个长达一小时（甚至七天）的 Cache-Control 印章，余下 9999 人全在半路被按头截胡，看到了免费的缓存结果。

二、 作为开发者，我本地怎么联调？ (实战指南)

第一步：唤醒沉睡的加工厂

进入 RomanceSpace-Backend 文件夹。

npm install
# 确保你配置好了 .env 密钥 (包含 Supabase & R2)
npm run dev

大掌柜在 localhost:3000 醒了。

第二步：把迎宾大礼堂支楞起来

进入 RomanceSpace-Frontend 文件夹。

npm install
npm run dev

大礼堂在 localhost:5173 开门营业了。你在上面瞎点，它会自动把请求发给加工厂。

第三步：让保安出来巡逻

进入 RomanceSpace-Worker 文件夹。

npm install
npx wrangler dev

此时，你的电脑化身为宇宙级 Cloudflare 节点，模拟一切真实发版后的请求劫持和缓存策略！

三、 系统运维的隐藏技能

⚠️ 零宕机封杀某个敏感前缀 (操作)
如果有人想注册 `admin.885201314.xyz`。作为站长，你不用去改源库里厚重的代码！
1. 登录 CF Dashboard 的 KV 里，找出 `__sys__blocklist`，向 JSON 加上 `["admin", "love"]`。
2. 给后端那台终年不关机的老迈 VPS 挂个号（Postman）: POST https://api.xxx.com/api/project/config/refresh-blocklist带上你的超强防刷密钥。
3. VPS 瞬间就把内存洗白重新录入了这个名单，自此全局锁死这几个名字！
