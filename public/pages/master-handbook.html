🌌 项目愿景

RomanceSpace 不仅仅是一个网页生成器。它是一个高性能、低成本、全球加速的 SaaS (Software as a Service) 平台。我们的目标是让每一个人都能在几秒钟内，为心爱的人交付一个极致精美的浪漫空间，并提供永久、稳定的全球访问保障。

💡 核心策略： 极致利用边缘计算 (Edge Computing) 降低 99% 的静态分发成本，同时保持后端逻辑的高度私密与安全。

🏗️ 宏观架构 (上帝视角)

整个系统采用了 CQRS (读写分离) 架构。我们将重体力的“写”操作（生成网页、计费、管理）与超大规模的“读”操作（全球访客查看页面）物理隔离。

核心组件说明：

组件 技术路径 角色职责
控制台 (GUI) Cloudflare Pages 用户交互、表单收集、Supabase 鉴权。
中央工厂 (API) VPS (Ubuntu + Nginx) 渲染 HTML 模板、操作 R2 与 KV、数据库同步。
数据中心 (DB) Supabase (PostgreSQL) 存储用户账户、订单、模板元数据。
全球分发 (Gate) Cloudflare Worker 拦截子域名请求，执行变量注入，毫秒级响应。

📊 数据生命周期 (Data Journey)

让我们以用户“小明”创建 love.885201314.xyz 为例，观察数据流转：

Step 1. 前端捕获：小明在 Builder 页面输入“致小红”，选择模板。前端生成 JSON 负载并发往 VPS API。

Step 2. 灌装成型：后端接收请求，从 R2 拉取对应模板的 HTML 骨架，通过正则引擎将文本注入 `{{ message }}` 等占位符中。

Step 3. 极速登记：后端将渲染好的 HTML 打包进 R2 的 /pages/love/index.html，并在 KV 中登记 `{"love": {"status": "active"}}`。

Step 4. 边缘唤醒：访客访问该链接。边缘 Worker 获取 KV 记录，直接从 R2 流式调取 HTML 返回。**整个流量完全不经过 VPS。**

🌱 仓库生态与协作

项目被拆分为 5 个核心仓库，通过 GitHub 高效协作：

  • RomanceSpace-Frontend: React 应用，负责 Builder 和用户中心。
  • RomanceSpace-Backend: Express 应用，负责核心逻辑与文件操作。
  • RomanceSpace-Worker: 负责子域名分发与路由的微码。
  • RomanceSpace-Templates: 纯净的 HTML/CSS 蓝图仓库。
  • RomanceSpace-Docs: 你现在看到的这套文档。
协作原则： 任何改变生产环境的操作，应优先通过 GitHub Actions 流程自动部署，严谨手动介入。

🚢 部署与运维圣经

1. 前端 (Pages)

Push 代码到 GitHub 后，Cloudflare Pages 会自动触发编译部署。环境变量 VITE_API_BASE_URL 需配置为生产环境后端地址。

2. 后端 (VPS)

# 标准部署流程 (Ubuntu)
1. 安装 Nginx 和 Node.js
2. 配置 PM2 进程管理: pm2 start src/server.js --name rs-api
3. Nginx 转发配置:
   location /api/ {
       proxy_pass http://localhost:3000/;
   }

3. 路由与分发 (Worker)

使用 npx wrangler deploy。必须绑定 ROMANCESPACE_KV 命名空间以及对应的 R2 Bucket 权限。

├── index.html   (核心骨架，带 {{ variable_id }})
├── config.json  (字段定义说明书)
└── style.css    (样式，建议内联)

AI 专用共创指令：

点击复制提示词

请为“浪漫空间” (RomanceSpace) 生成模板代码： 1. index.html：响应式 + 注入语法 {{ var_id }}。 2. config.json：必须包含 "name" (全小写下划线ID) 和 "title" (中文名)。格式：{"name": "...", "title": "...", "fields": [...] }。 3. 要求设计极其精美、浪漫，有 Premium 级别动画效果。

💎 优势与性能措施

  • 成本极低：通过 R2 和 KV 的超额免费额度，支撑全站 90% 的请求。
  • 零冷启动：Cloudflare Worker 无冷启动延迟，全球任一节点瞬间响应。
  • 高容灾：即便 VPS 宕机，已生成的千万个小站依然可以在 CDN 边缘正常运行。
  • 动静分离：API 请求同机中转，静态文件 Pages 分发，性能压榨到极致。
