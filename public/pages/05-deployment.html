Chapter 5

部署圣经：从服务器到边缘

本章记录了如何从零开始部署 RomanceSpace 的全栈环境，涵盖 VPS、Nginx、Cloudflare 等各个关键环节。

1. 后端与前端 (全栈 VPS 动静分离)

我们采用“邻居部署法”，前后端代码在同一 VPS 上放置。通过 Nginx 网关中转，消除跨域风险。

Nginx 极简双向转发配置

server {
    listen 80;
    server_name www.885201314.xyz;

    # 1. 前端 React 静态资源
    location / {
        root /opt/RomanceSpace-Frontend/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 2. 内网直连转发 API (3000 端口)
    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
    }

    # 3. 模板预览直连 (BSR 骨架分发)
    location /preview/ {
        proxy_pass http://127.0.0.1:3000/api/template/preview/;
    }
    
    # 4. 模板静态资产加速
    location ^~ /assets/ {
        proxy_pass http://127.0.0.1:3000;
        # 缓存配置...
    }
}

2. 环境初始化指南

1
基础依赖：安装 Node.js 20.x, PM2, Nginx, Certbot。
2
后端启动：克隆项目 -> 填入 .env (含 Supabase Service Key) -> pm2 start src/app.js。
3
前端构建：克隆项目 -> 设置 .env 指向 Supabase 公开 Key -> npm run build。

3. 极速更新工作流

以后每次修改代码后，只需在 VPS 执行：

  • 后端：git pull + pm2 restart romancespace-api。
  • 前端：git pull + npm run build (Nginx 会自动读取最新的 dist，0 重启)。
