🌐 边缘网关 (CF Worker) 绑定与部署

架构定位： 在 CQRS 架构中，Worker 被大幅度精简。它犹如坚不可摧的分发网关。它的唯一任务，就是在请求进来时，根据域名去 KV 和 R2 翻出缓存发送给客户，阻断高并发直接打穿后方。

一、 Wrangler 初始化

git clone https://github.com/XShen-Jason/RomanceSpace-Worker.git
cd RomanceSpace-Worker
npm install

登录你的 Cloudflare 账号（该操作会在浏览器弹窗授权）：

npx wrangler login

二、 Cloudflare 环境中创建必需组件

在使用之前，请确保你通过 CF 控制台或 Wrangler 命令建立了一个 KV Namespace 和一个 R2 Bucket：

1. 创建 KV 空间：建立路标牌

npx wrangler kv:namespace create "ROMANCESPACE_KV"

执行后终端会返回一串 ID（例如：id = "1b2c3d4f..."），请务必复制存好。

2. 创建 R2 仓库：建立资源静态仓

npx wrangler r2 bucket create romancespace-bucket

三、 配置 wrangler.toml 映射关系

打开项目根目录的 wrangler.toml，填入你刚刚申请好的资源库标识。

name = "romancespace-worker"
main = "src/index.js"
compatibility_date = "2024-03-01"

# 1. 绑定 KV
[[kv_namespaces]]
binding = "ROMANCESPACE_KV"
id = "刚才复制的那串ID填到这里"

# 2. 绑定 R2
[[r2_buckets]]
binding = "RS_BUCKET"
bucket_name = "romancespace-bucket"

四、 一键上云与 DNS 泛解析配置

npm run deploy
# 或者运行: npx wrangler deploy
⚡ 最重要的一步：泛解析指配 DNS 流量 部署完成后，你的 Worker 默认会被分配一个 workers.dev 的免费长丑域名，它并不能自动截获你的泛域名。

前往 Cloudflare 仪表盘绑定泛域名：

  1. 找到你的根域名 (885201314.xyz)。
  2. 点击左侧的 Workers 路由 (Worker Routes)。
  3. 点击 添加路由。
  4. 输入路由规则：*.885201314.xyz/*
    选择服务 (Service)：刚刚部署出来的 romancespace-worker
    环境 (Environment)：production
  5. 这就大功告成了！现在访问大批不存在的三级域名，将统统被截流发往该轻量网关处理。
