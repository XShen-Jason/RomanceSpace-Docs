🛡️ PM2 “防爆内存”日志切割配置指南（新手版）

当你的 Node.js 后端（romancespace-api）长期运行后，随着用户访问量的增加，pm2 生成的控制台日志文件会越来越大，最后可能塞满你的 VPS 硬盘，导致服务器崩溃死机。

为了解决这个问题，我们需要安装 PM2 官方提供的一个神器：pm2-logrotate。它会像保洁阿姨一样，每天自动帮你把旧日志打包压缩，并删除太老的日志。

步骤 1：安装日志切割插件

在你的 VPS 终端（任何目录下都可以），执行以下命令来安装插件：

pm2 install pm2-logrotate
💡 注意：是 pm2 install，不是 npm install。你可能会看到屏幕快速闪过一些下载信息，最后提示 "Module downloaded successfully"。

步骤 2：配置切割规则（复制粘贴即可）

安装好后，我们需要告诉这位“保洁阿姨”具体的打扫规则。我们设置的规则是：每天午夜切割一次，每个文件最大 10MB，最多保留最近 7 天的日志。

请依次在终端中复制并按回车执行以下命令：

# 设置每个日志文件最大不能超过 10MB（如果一天内超过 10MB 也会自动切割）
pm2 set pm2-logrotate:max_size 10M

# 设置最多只保留最近的 7 份历史日志（防止占满硬盘）
pm2 set pm2-logrotate:retain 7

# 启用日志文件 gzip 压缩（极致节省空间）
pm2 set pm2-logrotate:compress true

# 每天午夜 00:00 强制进行一次日志切割
pm2 set pm2-logrotate:rotateInterval '0 0 * * *'

步骤 3：验证是否配置成功

你想知道配置有没有生效？运行这行命令：

pm2 conf

你会看到一大串输出，只要在里面找到类似下面这样的字眼，即使顺序不一样，就说明大功告成了！

pm2-logrotate:
  max_size: 10M
  retain: 7
  compress: true
  rotateInterval: 0 0 * * *

总结

到这一步，你就彻底告别硬盘和内存被日志撑爆的隐患了。PM2 每天会在后台静默工作，不需要你做任何额外维护。你的香港 VPS 现在如同铁桶一般稳定！
