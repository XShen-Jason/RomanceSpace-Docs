🛡️ 管理员专属特权与隐藏 API (SaaS笔记版)

这份文档记录了系统中不对外公开的高级接口和安全机制。所有的 Admin API 在请求头中必须携带最高权限校验：X-Admin-Key: [你的超管密码]。

一、 高危词汇拦截库 (Blocklist)

为了防止用户利用我们的二级域名冒充官方（例如生成 admin.885201314.xyz）从事非法活动，系统内置了强大的防爆破黑名单。

⚠️ 必须封杀的危险黑名单（建议完整粘贴至 KV `__sys__blocklist`）
["admin", "root", "system", "sys", "api", "www", "doc", "docs", "document", "test", "demo", "love", "pay", "vip", "official", "support", "help", "login", "register", "cloudflare", "cf", "worker", "pages", "romancespace"]
POST /api/project/config/refresh-blocklist

作用：零内耗内存刷新术。你在 KV 里修改了黑名单后，它不会自动生效（为了省钱）。调一次这个接口，后端立刻读取最新 KV 注入内存。

curl -X POST https://api.885201314.xyz/api/project/config/refresh-blocklist \
  -H "X-Admin-Key: your_super_secret"

二、 其他隐藏管理 API

GET /api/project/:subdomain

作用：查水表。当你想知道某个前缀（如 xiaoming）到底用了什么模板，配置状态如何时使用。它直接从 KV 读取最轻量的节点路由配置。

POST /api/template/upload

作用：一键发布新模板。要求上传 FormData（含 `templateName`, `index.html`, `schema.json` 及其他配套资源），后端直接秒切资源树到 R2。

三、 已集成的可视化后台 (Admin Dashboard)

💡 运营人员上传模板入口：
为了方便非技术人员发版，可视化管理后台已无缝集成在 RomanceSpace-Frontend 主站中。

使用流程：
1. 访问入口： 浏览器访问隐藏路由 https://www.885201314.xyz/admin/upload。
2. 免密鉴权： 首次进入需输入 X-Admin-Key 密码，成功后浏览器自动记忆，后续发版长期免密。
3. 一键发布： 在拖拽区域放入模板的 index.html、schema.json 及其配套图片资源，输入模板名称（如 love_v2），点击发版即可。
4. 高速通道： 前端无需经过 Github，直接将文件打包直传 VPS 后端，并在上传成功后自动清除后端的缓存，前台用户秒级可见最新上线的模板。
