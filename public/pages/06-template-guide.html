Chapter 6

模板大师：共创规范与 AI 生产线

RomanceSpace 的生命力源于丰富多彩的模板。我们制定了极致简单的 **2.0 标准**，让不懂代码的创作者也能通过 AI 快速生成高品质模板。

1. 模板与前端的协议 (BSR 引擎)

我们的编辑器采用 BSR (Browser Side Rendering) 渲染。其技术桥梁如下：

  • 实时抓取：当用户点击特定模板，前端通过 /api/template/raw/:name 获取原始 HTML。
  • 注入 <base>：前端动态向 HTML 头部注入 <base href="/assets/{name}/">，这使得模板内的 CSS/图片能秒速定位到 R2 资源。
  • 正则脱水：前端直接用 JS 将 {{ id }} 批量替换为输入框的内容，并渲染进 iframe。全程不经过服务器。

2. 模板资产规范 (Must Have)

每一个上架模板必须包含以下“圣三一”文件：

- index.html (骨架): Mobile-First 响应式，必须包含 Viewport meta 防止缩放故障。
- config.json (表单): 定义 fields，映射后端输入框。
- thumb.jpg (门面): 600x400 画廊预览图。

3. 模板进阶：允许增加什么？

你可以额外包含以下内容来提升表现力：

  • 自研 JS (script.js)：实现复杂的互动动画（如飘落爱心、点击烟花）。
  • 自定义字体：通过 Google Fonts 引用（建议 CDN 方式）。
  • 背景音乐 (music.mp3)：利用 HTML5 <audio> 自动播放。

4. 变量注入详表

常用 config.json 及对应的 HTML 映射：

{
  "fields": [
    { "id": "main_title", "type": "text", "label": "主标题" },
    { "id": "love_bg", "type": "image", "label": "浪漫背景图" }
  ]
}

// HTML 中使用:
<h1>{{ main_title }}</h1>
<body style="background: url({{ love_bg }})">
