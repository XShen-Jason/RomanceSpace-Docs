Chapter 6

模板大师：共创规范与 AI 生产线

RomanceSpace 的生命力源于丰富多彩的模板。我们制定了极致简单的 **2.0 标准**，让不懂代码的创作者也能通过 AI 快速生成高品质模板。

1. 模板目录结构

一个标准的模板包由三个核心文件组成：

my-new-template/
├── index.html   (HTML 骨架，带注入语法)
├── config.json  (定义用户需要填写的表单字段)
└── thumb.jpg    (画廊预览图，建议 600x400)

2. 注入语法规范

我们使用双大括号 {{ variable_id }} 作为占位符。后端会在渲染时执行全局替换。

  • 动态文字：<h1>{{ title }}</h1>
  • 图片 URL：<img src="{{ bg_image }}">
  • 条件样式：<div style="color: {{ font_color }}">

3. config.json 详解

这是生成器表单的“大脑”，定义了用户在后台能改哪些东西：

{
  "name": "极简唯美周年庆",
  "fields": [
    {
      "id": "title",
      "label": "大标题",
      "type": "text",
      "default": "致最亲爱的你"
    },
    {
      "id": "content",
      "label": "情话内容",
      "type": "textarea",
      "default": "这里填入你的满腔爱意..."
    }
  ]
}
