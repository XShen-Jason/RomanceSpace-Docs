🚀 内部特权：上传新模板 (API 笔记)

这个接口只有内部开发人员或者系统部署脚本 (CI/CD) 才有资格调用。当你在本地写好了一个极其炫酷的新模板，你需要通过这个接口把它塞进 R2 的模板库里，让全网用户都能使用。

💡 为什么这是一个内部接口？ (分析)
模板上传本质上是把 HTML 文件长期保存在我们的核心资产库（R2 的 `/templates` 目录下）。为了防止别有用心的人上传含毒代码，这个接口必须使用 `X-Admin-Key` 进行绝对的白名单拦截。

一、 接口详情与调用方法 (操作说明)

⚠️ 门卫大爷的口令：
只有在 Request 头里带上 X-Admin-Key: 你的超强密钥 才能进门。钥匙配在后端的 `.env` 里。
POST https://api.885201314.xyz/api/template/upload
1
打包装箱 (FormData)
你需要发起一个 `multipart/form-data` 请求。里边带上 `templateName`（比如 `love_letter`）。然后把这个文件夹里的所有文件（HTML、CSS、JS、甚至图片）全作为文件流塞进去。
2
后端解析与存放 (运作流程)
后端收到后，会利用特权 S3 Client，把这堆文件塞进 R2 对应的 templates/love_letter/ 目录下。自此，前端就能通过模板列表接口刷出这个新产品了。

二、 调用代码范例 (怎样实现)

1. Node.js 后台调用范例

// 这是一个演示脚本，你可以写个自动脚本一键发布模板
const formData = new FormData();
formData.append("templateName", "love_letter");

formData.append("index.html", fs.createReadStream("./templates/love_letter/index.html"));
formData.append("style.css", fs.createReadStream("./templates/love_letter/style.css"));
formData.append("schema.json", fs.createReadStream("./templates/love_letter/schema.json"));

const response = await fetch("https://api.885201314.xyz/api/template/upload", {
  method: "POST",
  headers: {
    "X-Admin-Key": "这里写死你设置的超强密钥" // ! 必须填
  },
  body: formData
});

const result = await response.json();
console.log("云端发布完毕：", result);

2. 开发老手专区：cURL 极速调试

curl -X POST https://api.885201314.xyz/api/template/upload \
  -H "X-Admin-Key: 这里写死你设置的超强密钥" \
  -F "templateName=love_letter" \
  -F "index.html=@./templates/love_letter/index.html" \
  -F "style.css=@./templates/love_letter/style.css"
