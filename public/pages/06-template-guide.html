Chapter 6

模板大师：AI 驱动的生产规范

RomanceSpace 的生命力源于丰富多彩的模板。我们制定了极致简单的 **AI 2.0 标准**，让创作者能够通过协同 AI，在几分钟内产出具备商业品质的浪漫页面。

1. 核心开发原则 (AI-First)

  • 全屏响应式 (True Responsive)：必须完美适配移动端（竖屏）和电脑端（横屏）。建议使用 100vw / 100vh 布局。
  • “无构建”架构：严禁使用 Webpack/Vite 等打包工具。必须是原始的 index.html、内联 CSS 和原生 JS。
  • 单文件优先：为了实现“秒开”预览，建议将 CSS 和逻辑直接内联在 HTML 中。

2. 模板目录结构 (0 门槛上架)

虽然规范化文件夹能提升美感，但在代码层面，我们只强制要求 index.html。以下是推荐的完整结构：

my-new-template/
├── index.html   (必传) 核心 HTML，包含 {{ variable }} 语法
├── config.json  (必传) 模板大脑，定义字段逻辑
├── thumb.jpg    (建议) 画廊封面。后端不校验，仅供前端 UI 展示
└── assets/      (可选) 存图片、音乐等素材
⚠️ 技术真相： 后端文件校验逻辑仅检查 index.html 是否存在。thumb.jpg 并非技术必选项，它主要用于在前台“画廊”中给用户一个视觉预览。

3. 配置文件深度规范 (config.json)

这是模板的“大脑”，决定了用户在后台能改什么。必须使用以下标准格式：

{
  "name": "template-unique-id",
  "version": "1.0.0",
  "static": false, 
  "fields": [
    {
      "id": "title",
      "label": "网页标题",
      "placeholder": "展示在浏览器标签上的文字",
      "default": "致我最爱的人",
      "type": "text"
    },
    {
      "id": "paragraphs",
      "label": "浪漫留言",
      "placeholder": "输入你想对TA说的话...",
      "default": "在这个特别的日子里，我想对你说...",
      "type": "textarea"
    }
  ]
}

4. 变量注入与资源解析 (BSR 引擎)

自动资源映射

关键技术点： 当系统渲染你的模板时，会自动在 <head> 中注入一个 <base> 标签：

<base href="https://www.885201314.xyz/assets/{template_name}/">

这意味着你在模板中引用的 style.css 或 assets/logo.png 不需要写全路径，系统会自动将其映射到 R2 中的正确版本目录。请确保你的模板不包含硬编码的绝对路径。

注入语法

在 index.html 中，使用双大括号语法 {{ id }} 标记动态位置：

<title>{{ title }}</title>
<div class="message">{{ paragraphs }}</div>

视觉要求 (AI 重点关注)

  • Viewport 设置：必须包含 maximum-scale=1.0, user-scalable=no。
  • 背景适配：背景图必须使用 background-size: cover; background-position: center;。
  • 动效建议：推荐使用原生 CSS Keyframes，确保动画流畅且 0 外部依赖。
