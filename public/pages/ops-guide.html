一、 解决用户的燃眉之急 (FAQ 排错方案)

❓ 客户说：“生成了专属链接，但点开报 404 (Not Found)？”

怎么回事：极大概率是我们的后端 VPS 正在辛苦地用正则渲染、并在向 R2 写文件的路上卡顿了（比如国际路由抖动），这通常只持续几百毫秒。
怎么安抚：“亲，由于当前制作专属表白的人数较多，我们给您的浪漫加了点等待魔法。请您刷新一下页面或等2秒再点一次即可！”
技术兜底：前端的 BSR (浏览器实时渲染) 已经极大缓解了等待焦虑，如果在 Worker 遇到真 404，我们会让 Worker 给访问者返回一个友好的报错页或者 302 重定向到主站。

❓ 新的节日活动快到了，要上新模板，我们需要怎么打配合？

怎么回事：这是个经典的跨团队协作过程。
走个流程：
1. 运营/策划输出“七夕限定模板”的需求文档与文案。
2. 给到 UI 出设计图。
3. 甩给前端切图开发套入 RomanceSpace-Templates 库。
4. 工程师一敲 git push，它就被一秒内打包到云端。
5. 在主站配置上加上这个模板卡片，开始卖！
