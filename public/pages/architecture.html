🚀 架构与基础设施详情 (CQRS 深度解析)

这是一个极度优化的高并发小网页分发平台（RomanceSpace）。由于我们需要在近乎“免费”的前提下支撑极高的 C 端访问量，系统底层经过了 CQRS（命令查询职责分离）深度设计。

💡 CQRS 核心理念：
写操作（生成网页，并发低但极其耗费 CPU）交给 Node.js VPS；
读操作（查看网页，并发极高且只需 I/O）交给边缘节点 Cloudflare Worker。

一、 三大基础设施 (Infrastructure) 核心解析

底层数据不仅需要存储，还要应对极高并发的读取。我们组合了以下三大基石：

1. Cloudflare KV 极速键值对路由簿

  • 存放什么： 存放全网所有子域名的前缀标识（非完整域名）。存储格式并非单纯的布尔值，而是一段极其精简的 JSON 元数据，例如存入 {"xiaoming": {"status": 1, "template": "classic_love"}}。
    注：status: 1 代表正常，若是被系统封禁则改为 0 供边缘网关瞬间拦截。
  • 如何交互：
    - Backend (写)： 使用 Cloudflare API 强行写入新用户的前缀态与基础设置。
    - Worker (读)： 每个访客打开网页时，Worker 瞬间提取网址前缀，通过 env.ROMANCESPACE_KV.get('xiaoming', {type: 'json'}) 确认该前缀存在且合法，耗时 < 10ms。

2. Cloudflare R2 海量对象存储

  • 存放什么： 存放 Backend 渲染出来的 纯静态 HTML 文件，文件名同样基于域名前缀严格对应（如 xiaoming.html），以及模板的公共图片、CSS 资产。
  • 如何交互：
    - Backend (写)： 通过标准 AWS S3 SDK (PutObjectCommand) 把算好的代码以 [前缀].html 扔进仓库。
    - Worker (读)： 如果 KV 确认前缀存在，Worker 直接拼出文件名 env.ROMANCESPACE_R2.get('xiaoming.html') 把静态文件拿出来展示。

3. Supabase 关系型核心数据库

  • 存放什么： 存放用户填写的原始表单数据、订单记录、核心账号信息。
  • 如何交互：
    - Backend (读/写)： 接收到前端数据后，Backend 使用 @supabase/supabase-js 服务端特权密钥，安全持久化这些订单记录。Worker 和 Frontend 绝不触碰 Supabase！

4. API 旁路由 (api.885201314.xyz) 独立通信管道

  • 作用与定位： 这是一个被刻意独立出来的 API 旁路由，直接由 Cloudflare DNS 代理指向纯净的 VPS 服务器层，它不走 Worker 边缘网关的逻辑（因为 Worker 是用来分发和展现 C 端网页的）。
  • 如何调用： 前端代码中的 VITE_API_BASE_URL 指向的就是它。
    所有的请求都是以 api.885201314.xyz/api/... 开头的设计风格（例如：/api/project/render）。您必须带上后面的 /api 路径层级，因为这是 Express 后端设定的路由规则体系，能更好的进行版本控制 (如未来演进为 /api/v2/...)。

二、 四大执行仓库 (Repositories) 职责清单

1. RomanceSpace-Frontend (React)

核心动作：收集与呼叫。

提供让用户填表买单的 UI。收集到 {name: "小明", type: "love"} 后，通过 fetch(API_URL) 将数据 POST 给 Backend。自己从不保存任何状态。

2. RomanceSpace-Backend (Node.js VPS)

核心动作：重体力计算与数据入库。

接客后：（1）从 R2 拉取空模板；（2）跑正则匹配把“小明”印到 HTML 里；（3）把新 HTML 写入 R2；（4）把路由特征写入 KV；（5）把订单账单写入 Supabase。一人包揽所有 写 (Write) 操作，所以它需要最高权限的 .env 密钥。

3. RomanceSpace-Worker (边缘网关)

核心动作：极速拦访问与取货。

运行在 Cloudflare V8 引擎上。当几万人打开 xiaoming.885201314.xyz 时，流量全打在它身上。它只查 KV 判断有没有这个人，如果有，去 R2 拿出成品丢给访客。它包揽所有的 读 (Read) 操作，绝无越权修改。

4. RomanceSpace-Templates (纯静态资产)

核心动作：提供模板蓝本。

存放前端小哥手写的纯正 HTML/CSS 骨架和 schema.json。由独立脚本一键上传直指 R2。Backend 在渲染时拿这里的内容抄底。
