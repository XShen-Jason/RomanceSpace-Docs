🎨 Frontend 前端原理 (初学者笔记)

这份笔记将带你深入了解 RomanceSpace-Frontend 仓库。它是一个基于 Vite + React 构建的单页应用 (SPA)。你要记住的第一法则是：这是一个极其“傻白甜”的前端，所有的重活都不归它管！

💡 为什么前端要“傻白甜”？ (分析)
前端运行在用户的手机或浏览器里，环境既不安全性能又差。如果我们把拼接网页、连接数据库的活交给前端，不仅密钥会泄露，用户手机也可能卡死。所以前端只有一个任务：**让用户点得爽，然后把填好的表单扔给后端大哥 (VPS)。**

一、 前端的两大核心功能 (说明)

整个前端其实就两个至关重要的页面：

  • Gallery (画廊): 逛超市。让用户看到我们系统里都有什么好看的模板（纪念日、表白、婚礼等）。
  • Builder (工作台): 写贺卡。用户挑好模板后，在这里上传照片、写下给另一半的悄悄话。

二、 核心交互流程 (怎样实现的)

当一个用户想要制作一个页面时，前端是这样带他跑完全程的：

1
拉取超市货架 (Gallery)
动作：在画廊页面，前端向 VPS 大哥喊话：GET /api/template/list。
结果：大哥扔回一个数组，前端用 .map() 循环画出一排排漂亮的模板卡片。
2
进入工厂打字 (Builder - 动态表单)
动作：用户点进“结婚纪念日”模板。这个时候前端需要知道让用户填啥。
魔法：既然前端很“傻”，它怎么知道要画几个输入框？答案是读取模板骨架里的 schema.json（Manifest）。如果 JSON 说里面需要 boyName 和 date，React 就会自动生成这两个输入框。完全不需要我们为新模板特意改前端代码。
3
毫秒级自慰渲染 (BSR 预览)
动作：用户每打一个字，右边（或下面）的预览窗立马更新，完全不卡。
魔法：前端悄悄去 VPS 下载了一个“未开光的空 HTML” (`GET /raw/:name`)。然后偷偷在浏览器本地，把用户的填的字替换进这个 HTML 字符串里，然后塞给 `<iframe>`。由于不走网络，所以速度极快（0 额度消耗）。
4
交卷付款 (Publish 提交)
动作：用户点“生成网页”。
结果：前端把用户填的名字（如 xiaoming 和具体表单数据）打包成一个大包裹，POST /api/project/render 快递给 VPS。VPS 返回成功后，前端贴心地给用户跳出一个带有 ?preview=timestamp 的绝密无缓存链接，让他能立刻欣赏杰作。

三、 核心通信处与安全配置

⚠️ 绝对隔离铁律：
前端的 .env 文件中，只允许有这一行代码：
VITE_API_BASE_URL=https://api.885201314.xyz/api
绝不允许出现任何 SUPABASE_KEY 或 R2_TOKEN！前端只配和 VPS 也就是 api.885201314.xyz 直接对话。

为了代码好维护，所有跟 VPS 大哥对话的逻辑我们都放在了统一的文件（比如 `api/client.js`）里：

// 核心提交函数示例
export const renderProject = async (data) => {
    // 把小明填的表单 POST 过去
    const response = await fetch(`${import.meta.env.VITE_API_BASE_URL}/api/project/render`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(data)
    });
    return response.json(); 
};
