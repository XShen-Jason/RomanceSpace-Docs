🚀 开发者上传模板接口 (API)

💡 核心库机制： 目前系统内置的五大核心仓库之一 RomanceSpace-Templates，正是通过内部的 GitHub Actions 自动部署流水线，调用此 API 完成模板上传的。
如果您希望在自己的主站后台搭建一套可视化面板，可以通过主站后端携带鉴权密钥调用此接口，将包含 HTML/CSS/JS/图片 等静态文件直传至 Cloudflare。

接口详情 ⚙️

🔐 核心配置安全防线：
本系统通过 X-Admin-Key 请求头进行强制鉴权。请确保 .env 文件中配置了相应的验证密钥，绝不可在前端游览器 AJAX 请求中暴露此密钥。
POST https://api.885201314.xyz/api/template/upload

流程指南与示例

1
步骤 1：打包模板文件
举例：准备你开发好的 love_letter 模板文件夹，确保里面拥有 index.html 以及核心配置文件 schema.json。
2
步骤 2：组装 Form-Data 表单
举例：将文件加入 FormData，键名为云端相对路径（如 img/bg.jpg），键值为文件流。
3
步骤 3：发起接口调用
举例：携带管理员 Key，POST 至上述地址。成功后系统自动在后台滚动刷新全网缓存。

代码调用示例

cURL 示例
Node.js (FormData)
# 这个命令展示了如何同时传文本名，加上多个核心文件
curl -X POST https://api.885201314.xyz/api/template/upload \
  -H "X-Admin-Key: 你的超强密钥" \
  -F "templateName=love_letter" \
  -F "index.html=@./templates/love_letter/index.html" \
  -F "style.css=@./templates/love_letter/style.css"
// NodeJS 发起请求示例
const formData = new FormData();
formData.append("templateName", "love_letter");

formData.append("index.html", fs.createReadStream("./templates/love_letter/index.html"));
formData.append("style.css", fs.createReadStream("./templates/love_letter/style.css"));
formData.append("schema.json", fs.createReadStream("./templates/love_letter/schema.json"));

const response = await fetch("https://api.885201314.xyz/api/template/upload", {
  method: "POST",
  headers: {
    "X-Admin-Key": process.env.X_ADMIN_KEY
  },
  body: formData
});

const result = await response.json();
console.log("上传完毕：", result);
