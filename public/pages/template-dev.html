🧑‍💻 新模板开发与自动化部署指南 (笔记)

本指南面向想要为系统贡献新网页样式的切图仔。系统第五大独立仓库 RomanceSpace-Templates 没有任何复杂的构建工具，纯手工打造。它的灵魂在于一份名为 config.json 的“使用说明书”。

💡 为什么强调脱离构建工具？ (分析)
这些模板是要被人随时替换字符并且原封不动塞进 Cloudflare 边缘缓存的。如果是经过了高度打包的 React 或 Vue 产物，后端 VPS 甚至没法用正则找准 `{{name}}` 在哪个位置。越原始的 HTML/CSS/JS，对于这套系统来说越珍贵。
🤖 AI 辅助开发？ 我们专门准备了 《AI 专用模板开发规范》，包含一键复制的 Prompts！

一、 标准化的结构拆解

1
规范的目录结构
在 RomanceSpace-Templates/src 下为你的模板创建一个独立的文件夹。建议遵循以下结构：
src/[template_id]/
├── index.html —— (必填) 静态网页本体，包含 {{变量}}
├── config.json —— (必填) 模板配置文件，定义 UI 表单
├── style.css —— (建议) 建议独立出 CSS 文件简化 HTML
└── assets/ —— (建议) 放置图片、音频等静态素材
🚩 命名规范：
template_id 必须是小写字母、数字或下划线，且在仓库内全局唯一。这也就是该模板的“英文名”。
2
打上灵魂替换签 (Interpolation)
在 index.html 中，使用双大括号 {{id}} 标记动态内容。系统会在渲染时自动扫描并替换这些占位符。 
<!-- 示例：index.html -->
<h1>{{title}}</h1>
<p>致 {{receiver}}：</p>
<div class="content">{{message}}</div>
3
详解 Config.json 说明书
config.json 决定了前端 Builder 页面会生成什么样的表单。

字段详细说明

字段名 必填 类型 描述
name 是 String 模板唯一标识，需与文件夹名一致。
fields 是 Array 配置项列表。
fields[].id 是 String 对应 HTML 中的 {{id}}。
fields[].label 是 String 前端表单显示的名称（中文）。
fields[].type 否 Enum text (默认) 或 textarea。
fields[].default 否 String 表单默认预填的内容。
fields[].placeholder 否 String 输入框为空时的提示语。
static 否 Boolean 是否为静态模板。若为 true，则不渲染 fields。

一键复制：标准 config.json 样板

{
  "name": "my_romantic_template",
  "version": "1.0.0",
  "static": false,
  "fields": [
    {
      "id": "title",
      "label": "网页标题",
      "placeholder": "例如：致最亲爱的你",
      "default": "告白气球",
      "type": "text"
    },
    {
      "id": "message",
      "label": "浪漫寄语",
      "placeholder": "想对 TA 说的话...",
      "default": "我想和你虚度时光。",
      "type": "textarea"
    }
  ]
}

一键复制：标准 index.html 样板

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>{{title}}</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div class="container">
        <h1>{{title}}</h1>
        <p>{{message}}</p>
    </div>
</body>
</html>

二、 推向线上 (两套部署方案)

方案 A：可视化后台一键上传（推荐运营人员首选）

系统在前端主站为您提供了一个极简的隐藏管理后台，完全脱离枯燥的命令行代码。

1
登录后台：
浏览器访问 https://www.885201314.xyz/admin/upload，输入管理员密码。
2
拖拽上传：
将你写好的 index.html 和 config.json （以及配套图片）全部选中，拖进网页的上传框内。
3
秒级生发：
填写好你的模板英文文件夹名，点击“一键发布”。所有文件会瞬间直达云端 R2 存储桶，并在前台立刻生效。

方案 B：GitOps 自动化流水线（推荐资深极客）

如果你将模板文件夹 git commit 提交到 Github 的 RomanceSpace-Templates 仓库主分支。仓库里的 Github Actions 就会自动启动：为你自动打包文件夹 -> 跨海调用 VPS 的 /api/template/upload 接口 -> 自动推入 R2。

# 极客的日常只要敲三行代码：
git add .
git commit -m "feat: 新增了一个表白特效网页"
git push

就是这么丝滑！根据您的团队人员构成，随意选择最合适的一套方案即可。
