🧩 模板定制参数 (Data) 字典库

做为 RomanceSpace-Templates 的核心沉淀，这里列出了目前五大仓库体系中支持传入渲染引擎的 JSON 定义。

💌 模板一：表白信 (love_letter)

字段名 类型 作用与说明
title String 页面顶部主标题。
sender String 送件人署名。
receiver String 收件人称呼。
paragraphs Array[Str] 多段落组成的寄语正文。 
{
  "type": "love_letter",
  "data": {
    "title": "给最爱的红红",
    "sender": "小明",
    "receiver": "小红",
    "paragraphs": [
      "这是我遇见你的第100天。",
      "感谢命运让我们相视一笑。"
    ]
  }
}

🗓️ 模板二：相爱纪念日 (anniversary)

字段名 类型 作用与说明
title String 中心大字号粗体标题。
startDate String 纪元的开始，用来算计时 (如 2024-01-01)。
names Array[Str] 限定2个元素，情侣双方的昵称。
message String 底层情话或者宣言。 
{
  "type": "anniversary",
  "data": {
    "title": "小明与小红的纪念日",
    "startDate": "2021-05-20",
    "names": ["Xiaoming", "Xiaohong"],
    "message": "永远在一起的见证哦。"
  }
}
