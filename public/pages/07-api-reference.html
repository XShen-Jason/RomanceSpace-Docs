Chapter 7

API 字典：核心功能汇总

本章为开发者提供 RomanceSpace Backend 的全量接口参考。所有接口均挂载在 www.885201314.xyz/api/ 之下。

1. 模板管理 (Template APIs)

负责模板的生命周期管理，从上传到分发。

接口 方法 鉴权 说明
/template/list GET 公开 获取全量可用模板列表，包含字段元数据。
/template/raw/:name GET 公开 获取指定模板的原始 HTML（BSR 编辑器核心）。
/template/preview/:name GET 公开 服务端渲染模板预览页。
/template/upload POST Admin 通过 Multipart 上传模板包（含 config.json 校验）。
/template/sync-local POST Admin 强制触发 VPS 与 GitHub/本地源码库的同步。

2. 项目渲染与路由 (Project APIs)

系统的“心脏”，处理页面生成与访问分配。

接口 方法 鉴权 说明
/project/render POST Auth 核心渲染接口。接收 JSON 数据，写入 R2 并同步边缘路由。
/:subdomain GET Admin 获取该子域名的原始配置信息（用于后台管理）。
/project/config/refresh-blocklist POST Admin 清除 VPS 内存中的域名黑名单缓存并重新从 KV 加载。

3. 静态资产与监控 (Infrastructure)

接口 方法 说明
/assets/:type/* GET 模板静态资源（图片/JS/CSS）分发，支持多版本缓存。
/health GET 基础健康检查，返回系统时间戳。
/templates.json GET 静态化的模板列表资源，由 Nginx 直接响应（极低延迟）。
🔒 管理员鉴权 (Admin Key)
所有标记为 Admin 的接口，必须在 Header 中携带 X-Admin-Key。该 Key 在后端 .env 中配置。
