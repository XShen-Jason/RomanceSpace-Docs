🧩 模板定制参数字典 (Data Payload)

做为 RomanceSpace-Templates 的核心沉淀，前端在调用总网关的 /render 接口时，到底该在 data 对象里包装些什么字段？全由这个字典说了算。

💡 设计原则 (分析)：
不同的模板（如信件、相册、音乐盒）所需要的排版数据完全不一样。通过这个字典，后端拿到这个 `data` 对象后，只需要无脑用正则去把 HTML 里对应的 `{{key}}` 替换掉就行，做到真正的动态化。

💌 模板 1：经典表白信 (love_letter)

字段名 (key) 类型 说明
title String 这封信的醒目大标题（如：给最爱的红红）。
sender String 发件人（落款）的名字。
receiver String 收件人（开头）的称呼。
paragraphs Array[Str] 正文内容。你可以传一个数组，后端会把它渲染成多个 <p> 标签。 
// 前端请求时，data 应该是这样的：
{
  "title": "给最爱的红红",
  "sender": "小明",
  "receiver": "小红",
  "paragraphs": [
    "这是我遇见你的第100天。",
    "感谢命运让我们相视一笑。"
  ]
}

🗓️ 模板 2：相爱纪念日 (anniversary)

字段名 (key) 类型 说明
title String 大字号标题。
startDate String 纪元的开始，用来在前端页面里跑动态倒计时 JS (如 2024-01-01)。
names Array[Str] 限定 2 个元素，装载情侣双方的昵称。
message String 底层的甜蜜情话。 
// 前端请求时，data 应该是这样的：
{
  "title": "小明与小红的纪念日",
  "startDate": "2021-05-20",
  "names": ["Xiaoming", "Xiaohong"],
  "message": "永远在一起的见证哦。"
}
